# ⚡ ByteSac — Landing Page Oficial

> **Diagnóstico claro. Soluciones reales.**

Sitio web oficial y landing page de comercialización para **ByteSac**, una empresa de servicios tecnológicos orientada a brindar soluciones integrales de software, automatización e infraestructura técnica a PyMEs, pequeños comercios y profesionales independientes.

---

## 🚀 Propuesta de Valor

En **ByteSac** unificamos las necesidades digitales y operativas de un negocio para que no tenga que tratar con múltiples proveedores:
- **Infraestructura de Software:** Sitios web modernos, catálogos online autogestionables y tiendas virtuales optimizadas.
- **Automatización Comercial:** Integración de chatbots, atención automatizada 24/7 en WhatsApp y gestión fluida de leads.
- **Soporte Técnico Integral:** Mantenimiento preventivo, diagnóstico y reparación de equipos informáticos con logística de retiro y entrega a domicilio.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico:** Estructura limpia y accesible pensada para optimización en motores de búsqueda (SEO local).
- **Tailwind CSS v3:** Framework utility-first para diseño responsivo, moderno y ligero.
- **Lucide Icons & SVGs Inline:** Iconografía vectorial ultrarrápida sin sobrecarga de dependencias externas.
- **Google Fonts (Inter):** Tipografía clara de alta legibilidad en pantallas digitales.

---

## 📌 Estructura de la Landing Page

1. **Header & Navegación:** Identidad de marca con logo vectorial y botón directo de alta conversión hacia WhatsApp.
2. **Hero Section:** Mensaje principal enfocando el lema *"Comenzá a aprovechar las herramientas modernas"*.
3. **Servicios Principales:** Bloque de 3 columnas destacando Desarrollo Web, Automatizaciones y Soporte Técnico.
4. **Sección Diferencial:** Explicación del modelo de atención integral (Hardware + Software, Trato directo y Retiro a domicilio).
5. **Preguntas Frecuentes (FAQ):** Componente interactivo para resolver objeciones operativas rápidamente.
6. **Footer & Redes:** Contactos directos y accesos a perfiles oficiales.
