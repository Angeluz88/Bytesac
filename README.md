# **🚀 Descripción del Proyecto**

Landing page comercial desarrollada para presentar la propuesta de servicios integrales de **ByteSac**, una iniciativa orientada a impulsar la transformación digital y el soporte tecnológico de PyMEs, pequeños comercios y profesionales independientes.

El sitio web está optimizado para ofrecer una experiencia de usuario fluida, moderna y con una clara orientación a la conversión de clientes a través de un diseño responsive y de carga ultrarrápida.

---

# **🛠️ Tecnologías Utilizadas**

* **HTML5 Semántico**: Estructuración clara y accesible de contenidos para optimización SEO.  
* **Tailwind CSS v3**: Framework CSS *utility-first* para un diseño estilizado, responsive y ligero.  
* **Lucide Icons & SVGs Inline**: Iconografía vectorial escalable de alto rendimiento visual.  
* **Google Fonts (Inter)**: Tipografía sans-serif moderna orientada a la legibilidad en pantallas.

# **💻 Despliegue Local**

Sigue estos sencillos pasos para clonar y ejecutar el proyecto en tu entorno local:

## **1\. Clonar el repositorio**

Abre tu terminal y ejecuta el siguiente comando:git clone https\://github.com/tu-usuario/bytesac-landing.git

## **2\. Acceder al directorio del proyecto**

cd bytesac-landing

## **3\. Ejecución en el navegador**

* **Opción A (Con Live Server en VS Code):**  
  1. Abre la carpeta del proyecto en Visual Studio Code.  
  2. Haz clic derecho sobre el archivo `index.html`.  
  3. Selecciona **"Open with Live Server"**.  
* **Opción B (Directa sin servidor):**  
  1. Haz doble clic sobre el archivo `index.html` en tu navegador predeterminado.
